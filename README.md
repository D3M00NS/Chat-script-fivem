# Chat-script-fivem

[Zyon 3.3.1 — baixar pacote completo](downloads/ZyonMenu-v3.3.1-completo.zip) · [Fontes e instruções](zyon-v3/README.md) · [Validação](zyon-v3/docs/VALIDACAO.md)

Versão de teste Windows x64/FiveM b3258 com módulo instalado somente no cliente pelo próprio executável. Não exige cargo de administrador ou recurso no servidor; o servidor precisa já permitir plugins/ScriptHook e usar pure level abaixo de 2.

Mantém GodMode, noclip/voar, invisibilidade, munição, suicídio e revive nativo. Acrescenta ações de portas do veículo e um protótipo experimental de Silent Aim, que pode não produzir tiro ou acerto. Não identifica ADMs nem limpa o estado médico ESX/QBCore. O comportamento real no Windows/FiveM ainda não foi validado.

Na atualização, feche o FiveM e use **Preparar módulo** novamente antes de abrir o jogo. A versão 3.3.1 verifica a instalação usada pelo processo do FiveM, identifica arquivo ausente/desatualizado e preserva o erro real de inicialização do plugin. O banner oferece **Usar cliente local** no modo externo e orienta a preparação no modo local. Um arquivo instalado não comprova execução nativa; a autorização de plugins continua necessária.
