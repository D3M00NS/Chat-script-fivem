# ZyonMenu — arquivos para download

Aplicativo externo Windows 10 x64 e recurso administrativo FiveM.

- `ZyonMenu-completo.zip`: executável com runtime embutido, recurso e fontes.
- `ZyonMenu-compacto.zip`: executável menor, recurso e fontes; requer .NET Desktop Runtime 8 x64.

O recurso `zyon_admin_menu` precisa ser instalado na cidade, com token e licença/ACE configurados. Silent Aim permanece desativado. Compilação e testes automatizados passam; a janela no Windows e o comportamento real no FiveM não foram validados neste ambiente Linux.

O pacote não inclui os executáveis enviados para análise nem credenciais reais.
